═══════════════════════════════════════════════════════════════════
ЛОГИКА ПЛЕЕРА (player.js)
═══════════════════════════════════════════════════════════════════
Работает с МНОЖЕСТВОМ плееров на странице. Каждый плеер —
<div class="player" data-audio="путь/к/треку.mp3">.
Скрипт ищет все .player и инициализирует каждый отдельно.

Волна берётся из глобальной переменной WAVEFORM_PEAKS
(подключается из waveform_data.js перед player.js).
Пока для всех плееров одна и та же волна. Когда появятся новые
треки — для каждого нужно будет сгенерировать свой waveform через
generate_waveform.py и сохранить отдельно.

Структура плеера в HTML (обязательные классы):
  .player (data-audio="...")
    .cover-wrapper > .cover-art
    .player-content
      .player-header
        .play-btn
        .track-info > .track-title + .track-artist
        .download-icon
      .wave-container > .wave-canvas
      .progress-bar > .progress-fill
      .time-display > .current-time + .duration

Чтобы добавить трек — копируем блок .player, меняем data-audio,
.track-title, href у .download-icon. Для нового трека генерируем
свой waveform и либо подменяем WAVEFORM_PEAKS, либо передаём
пики через data-атрибут (нужна доработка).
